01 — Introducere

Ce este GitHub?

GitHub este o platformă online pentru găzduirea codului sursă, colaborarea între programatori și gestionarea proiectelor software. Este construită în jurul sistemului de control al versiunilor Git.

Pe GitHub poți salva proiecte, urmări modificările codului, raporta probleme și lucra împreună cu alți dezvoltatori, indiferent de locul în care se află.

Platforma este folosită atât de începători și studenți, cât și de echipe profesionale și organizații din întreaga lume.

02 — De ce GitHub?

Avantajele GitHub

Instrumente utile care fac dezvoltarea software mai organizată, mai rapidă și mai colaborativă.

🤝

Colaborare ușoară

Mai mulți programatori pot lucra la același proiect, pot propune modificări și pot verifica schimbările înainte de integrarea lor.

🕓

Istoricul versiunilor

Git păstrează istoricul modificărilor, astfel încât poți vedea ce s-a schimbat și poți reveni la versiuni anterioare ale codului.

🌍

Proiecte open-source

Poți descoperi proiecte publice, studia codul altor dezvoltatori și contribui la comunitatea globală de programare.

☁️

Cod disponibil online

Repository-urile găzduite online îți permit să accesezi și să gestionezi proiectele de pe dispozitive diferite.

🛡️

Gestionarea accesului

Poți administra permisiunile colaboratorilor și folosi instrumente de securitate pentru protejarea proiectelor.

🚀

Automatizare

Cu GitHub Actions poți automatiza teste, verificări ale codului și anumite procese de publicare a aplicațiilor.

03 — Instrumente

Funcționalități importante

GitHub oferă mai mult decât un loc unde să păstrezi codul.

📁

Repositories

Spații în care păstrezi fișierele, codul sursă, istoricul modificărilor și documentația proiectului.

🔀

Pull Requests

Propui modificări, discuți despre cod și verifici contribuțiile înainte de a le integra.

🐛

Issues

Înregistrezi erori, propui idei și urmărești sarcinile care trebuie rezolvate.

⚙️

GitHub Actions

Automatizezi fluxuri de lucru, teste și procese repetitive din dezvoltarea software.

📚

README și documentație

Explici scopul proiectului, modul de instalare, utilizarea și instrucțiunile importante.

🌐

GitHub Pages

Publici anumite site-uri statice direct dintr-un repository, inclusiv pagini HTML, CSS și JavaScript.

04 — Primii pași

Cum se utilizează GitHub?

Poți începe cu un proiect simplu și îl poți dezvolta treptat, pe măsură ce înveți.

1

Creează un cont

Accesează GitHub și înregistrează-te pentru a-ți crea profilul de dezvoltator.

2

Creează un repository

Repository-ul va conține fișierele și documentația proiectului tău.

3

Adaugă codul

Încarcă fișiere direct pe site sau utilizează Git pentru a gestiona modificările local.

4

Colaborează și publică

Distribuie proiectul, acceptă contribuții și, dacă este un site static, explorează opțiunea GitHub Pages.
